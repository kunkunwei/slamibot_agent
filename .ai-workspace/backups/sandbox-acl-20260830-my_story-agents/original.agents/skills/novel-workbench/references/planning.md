# Planning Reference

## Purpose

把作品前提逐层转成可执行的总纲、篇章计划和章节里程碑，同时保持因果链由人物选择推动，并显式管理叙事债务。

## Required inputs

- 已确认 premise、主题、世界规则与结局约束。
- 主角核心欲望、恐惧、错误信念、可承受代价和不可越界事项。
- 当前 Canon、已确认 State/Delta、活跃伏笔与用户新增要求。
- 计划层级：master outline、arc plan 或 chapter milestones。

## Procedure

1. 从 premise 提炼核心冲突、故事承诺、终局问题和不可违背的规则。
2. 形成 master outline：起点、不可逆转折、中段重估、最低点、高潮选择、结局代价；每个节点写明“因为 A，所以人物选择 B，导致 C”。
3. 将总纲切成 arc：每个篇章定义外部目标、内部变化、对手压力、升级阶梯、篇章高潮、收束结果与下一篇章输入。
4. 将 arc 切成 chapter milestones：每章标注目的、前置因果、人物主动选择、局势变化、信息释放、情绪位移和章末钩子。
5. 对每个关键转折执行因果检查：删除巧合后是否仍成立；行动者是否有当时可知的动机；代价是否落地。
6. 建立叙事债务表：承诺、悬念、伏笔、情感债、世界规则展示；记录创建点、预期回收窗、延期成本和当前状态。
7. 逆向检查结局：高潮选择是否由前文人物选择累积而来，前期承诺是否得到兑现、反转或有意拒绝。

## Outputs

- `novel/outlines/master-outline.md` 的结构决策或定向补丁。
- `novel/outlines/arcs/arc-001.md` 形式的篇章计划。
- 章节里程碑清单，供 `chapter-contract.md` 实例化。
- 已识别的叙事债务、依赖、风险与需要用户裁决的问题。

## Stop/escalate conditions

- 计划与用户确认、已发布正文或 Canon 冲突时停止并报告证据。
- 涉及结局、长期主线、核心人物不可逆转变或重大伏笔时升级 Sol。
- 关键转折只能依赖巧合、人物无动机行为或未建立规则时，停止下钻章节。
- 输入不足以区分多个互斥方向时，列出选项和代价，请用户裁决。
