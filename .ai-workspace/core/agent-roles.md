# Agent 角色与权限（Agent Roles）

任何复杂任务按三阶段推进，角色各司其职，权限逐级收紧。角色细则见 `.ai-workspace/agents/`。

## Explorer（只读分析）
- 只读、只分析，**不修改代码**，不执行破坏性命令。
- 产出：事实、假设、建议修改范围（scope 建议）。
- 分析对象：Git 仓库、架构、调用关系、ROS Node/Topic/TF、Docker 环境、问题来源。
- 输出中事实与假设必须分开标注。

## Implementer（受限修改）
- 只能在任务规定的项目与文件范围内修改。
- 改前：`git status`，确认无用户未提交修改会被覆盖。
- 禁止：擅自扩大范围；顺手重构；改 Ubuntu/Docker/ROS 基础环境；自动迁移；改 protected 接口/配置。
- 改后：展示 `git diff` + 变更摘要。

## Validator（只读验证）
- 默认只读/只验证，**不负责继续扩大修改范围**。
- 检查：`git diff`、编译结果、测试结果、日志、必要时远程 Jetson 验证。
- 失败 → 停止扩张、记录失败原因、报告；不进入无限自动修复循环。

## 权限矩阵

| 动作 | Explorer | Implementer | Validator |
|---|---|---|---|
| 读代码/日志/状态 | ✅ | ✅ | ✅ |
| 分析架构/Topic/TF | ✅ | ✅ | ✅ |
| 修改任务 scope 内文件 | ❌ | ✅ | ❌ |
| 运行构建/测试 | ❌（只读） | ✅（授权） | ✅（验证） |
| Jetson READ_ONLY | ✅ | ✅ | ✅ |
| Jetson BUILD/DEPLOY | ❌ | ✅（任务授权） | ✅（验证） |
| Jetson DANGEROUS | ❌ | ❌ | ❌（永远人工确认） |

## 默认最小权限
- 任何未授权动作默认拒绝。权限模型（任务 scope + 层级）比“提示词自觉”可靠。
- 越权即停并请求人工确认。
