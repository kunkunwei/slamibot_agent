# 架构决策记录（ADR）

## 格式
每个决策一个文件 `ADR-XXXX-<短横线标题>.md`，包含：
- **背景**：为什么需要决策。
- **问题**：要解决的具体问题。
- **方案**：候选方案。
- **选择**：最终选择。
- **原因**：为什么选它。
- **影响**：正/负面影响、代价。
- **替代方案**：被否决的方案及原因。

## 规则
- 决策是「当时的事实 + 理由」，供后续参考；**不凌驾于当前事实源与代码状态**。
- 与事实源冲突时，以当前事实源与代码为准，并更新 ADR 或新增 ADR。
