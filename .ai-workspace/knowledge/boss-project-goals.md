# BOSS 原定 D360 / BOX 项目研发目标

> 来源：用户于 2026-08-20 提供的原始目标描述。本文记录目标，不等同于当前已实现状态；未核验项统一标记为 NEEDS_CONFIRMATION。

## 1. BOX、图数传与手持遥控器

- BOX 集成图数传和手持遥控器链路。
- 手持遥控器支持通过触屏点选或实体键快速进入导航模式。
- 摇杆支持及时手动控制机器人运动和急停。
- 实体键支持切换任务执行时的：
  - 黄灯爆闪模式；
  - 常规三色灯模式。
- 图数传链路支持从遥控器远程对 BOX 小喇叭喊话。
- BOX 上有声卡，D360/Jetson 应能识别并使用该声卡。

## 2. 遥控器 APP 常规操作

- 遥控器上的 APP 支持采集等常规操作。
- 支持 RTK 设置。
- 支持利用 BOX 的 4G 上网模块访问 CORS 网络账号并获取 RTK 固定解。
- BOX 插入/接入后，4G 上网功能应能自动配置。
- 4G 上网功能已实现；自动配置和 CORS/RTK 固定解链路仍需按当前版本重新验收。

## 3. 环形麦克风与语音控制

- BOX 搭载环形麦克风。
- 支持语音离线识别，并驱动宇树 Go2 执行宇树 APP 已有的动作，例如打招呼。
- 重点语音导航指令：
  - “开始建图”
  - “建图完毕”
  - “标记目标点1”
  - “导航到图书馆”
  - “导航到停车场”
  - “导航回家充电”（充电功能暂不开发）
- “标记目标点1”需结合遥控器摇杆运动到目标位置后执行。
- 利用环形麦克风声场实现“到我跟前来”，用于取送/托运物品功能。
- 当前 BOX 不作为项目阻塞项，已有其它 BOX 可替换。现阶段问题转为：APP 到 BOX 的喊话和回传链路可能打断语音识别。

## 4. D360 巡检识别与拍照回传

- 部署基础识别、对比和拍照回传功能，包括：
  - 灭火器设施缺失识别；
  - 停车场违章停车识别；
  - 配电箱指示灯记录拍照。
- 结果回传至遥控器或云端；当前目标至少提供远程访问端口。
- 具体模型、数据集、准确率、回传协议和验收标准：NEEDS_CONFIRMATION。

## 5. 2D/3D 导航适配与前端显示

- 遥控器导航界面支持小车 2D 导航和 Go2 3D 导航切换。
- 前端显示导航地图时，最好在同一屏幕支持前摄像头画面显示。
- 摄像头画面支持可大可小/可切换显示。
- 当前事实：Scout mini 2D 为 ROS1 产品线；Go2 3D 为独立 ROS2 Humble 产品线，禁止混用启动命令和接口。

## 6. 当前已知实现和待验收边界

- 2D WEB/APP 栅格地图显示：已人工验收通过。
- APP/WEB 双 rosbridge：APP/WEB 使用 9090，FastAPI 内部使用 19090，已完成联调基础验证。
- Go2 WebRTC 控制和 `/cmd_vel` 到 `Move(vx, vy, vyaw)` 桥接：工作台已有资料，安全控制和完整业务闭环仍需专项验收。
- R1 环形麦克风：新 BOX 目前未被 Jetson USB 识别，硬件问题待处理。
- 巡检识别、灯光模式、喊话、2D/3D 切换、同屏视频、自动 4G/CORS 配置：本工作区当前没有完整验收证据，状态为 NEEDS_CONFIRMATION。
