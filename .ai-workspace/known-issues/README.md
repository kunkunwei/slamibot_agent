# 已知问题（known-issues）

## 用途
记录历史踩坑，供后续 AI 与开发者参考。典型：Planner 超时、TF 问题、rosbridge 异常、
Docker 网络问题、Jetson 特定问题、ROS1/ROS2 差异。

## 格式
每个问题一个 `.md`，包含：现象、复现、根因、解决/规避、状态（open/resolved）、日期、相关仓库/栈。

## 规则
- 作为参考，不凌驾于当前事实源与代码状态。
- 新问题先记录再修复，避免重复踩坑。
